# Zotero Project Manager 1.2.0

Copy links from Zotero directly into Emacs Org or Markdown notes, including
Obsidian. One Zotero Project Manager context menu now groups copying, collection
exports, and Settings. Existing exports remain unchanged.

## New link commands

- Copy Link → Org / Markdown / Zotero URI for collections, paper records, and PDFs.
- Copy Link in This Collection remembers the collection from which you copy a paper.
- Copy Multiple Links copies selected paper records/PDFs, one link per line.
- PDF reader menus copy links to physical pages and saved annotations.

Only My Library is supported. Unsupported entries and invalid keys cannot produce
links; invalid batches leave the clipboard unchanged. Copying requires no exports,
Actions & Tags, zotxt, bibliography style, or external process.

## Install or update

In Zotero choose Tools → Plugins → gear → Check for Updates, or download the
attached zpm-zotero-1.2.0.xpi and choose Install Plugin From File… in the same menu.
Install over the previous version, including 1.2.0 previews; restart if requested.

Emacs users should install the named handlers from the
[beginner guide](https://github.com/sbilmis/zotero-project-manager/blob/v1.2.0/docs/LINKS.md).
Existing zotxt links and APA settings can coexist with these native links.
For PDFs to open internally, set Zotero Settings → General → Open PDFs using → Zotero.
Collection-specific links can stop working if collection membership changes.

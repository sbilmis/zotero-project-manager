# Zotero Project Manager 1.3.0

Browse papers from your current Zotero collection directly in an Emacs Org note,
even when you cannot remember the article title.

## Commands

- `M-x zpm-insert-paper-link`: choose by author, year, title, and key; insert an Org link.
- `M-x zpm-open-paper`: select the chosen record in Zotero without inserting text.
- `M-x zpm-remember-collection`: remember a collection in the note; save to persist.
- `M-x zpm-forget-collection`: follow Zotero's selected collection again.
- `M-x zpm-picker-setup`: show setup help, also offered when local access is disabled.

The endpoint is local and read-only. Only direct regular records in My Library
collections are listed; attachments, notes, deleted entries, and subcollections
are excluded. Existing native links and exports are unchanged.

## Install or update

In Zotero: Tools → Plugins → gear → Check for Updates, or install the attached
zpm-zotero-1.3.0.xpi using Install Plugin From File…. Restart if prompted.
Stable 1.3.0 supersedes both picker previews.

Enable Zotero Settings → Advanced → Allow other applications on this computer
to communicate with Zotero. No online API key is required.

**Emacs users must also install the Emacs module and link handlers:** the XPI
cannot install Emacs configuration. Follow the
[beginner setup guide](https://github.com/sbilmis/zotero-project-manager/blob/v1.3.0/docs/PAPER-PICKER.md).
Keep existing zotxt and APA settings. No new keybindings are required.

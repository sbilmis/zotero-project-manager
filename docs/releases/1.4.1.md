# Zotero Project Manager (ZPM) 1.4.1

**Status:** Released 2026-09-29

This patch restores annotation-link copying, removes the warning icon from
successful export results, and clarifies where exported summaries are saved.

## Fixes

### Annotation links

In 1.4.0, right-clicking an annotation could show a **ZPM** row with no usable
submenu, even though copying links from plain page text worked.

Right-click one saved annotation on the page or in the annotations sidebar and
choose **ZPM: Copy Annotation Link (Org)**, **(Markdown)**, or **(Zotero URI)**.
These commands appear directly in the menu because Zotero's internal annotation
menu does not render nested submenus. Page and thumbnail link menus keep their
existing **ZPM → Copy PDF Page Link** structure.

Unsupported selections, including multiple annotations and group-library PDFs,
keep the commands disabled. Copying revalidates the target and preserves the
clipboard if the annotation is no longer available.

### Export results and documentation

Successful exports now show a neutral, selectable results dialog with an **OK**
button. Exports with errors retain warning alerts. Missing attachments display
**Export finished with missing files**, so an incomplete export is not presented
as an unqualified success.

The workspace example now shows the actual generated summary,
**`.zpm/export-summary.md`**. ZPM does not generate a root `README.md`; one can be
an exported Zotero attachment or a file you create yourself. Existing files and
the generated workspace layout are unchanged.

## Compatibility and upgrade

- Plugin 1.4.1 targets Zotero 9 and 10.0.x. Python CLI remains at 1.3.2.
- Existing links, Emacs configuration, export settings, and workspaces need no
  migration. The export and synchronization behavior is unchanged.
- Use **Tools → Plugins → gear → Check for Updates**, or download
  `zpm-zotero-1.4.1.xpi` from the
  [1.4.1 release](https://github.com/sbilmis/zotero-project-manager/releases/tag/v1.4.1)
  and use **Install Plugin From File…**. Restart if prompted.

If you are still using 1.4.0, export with **Collection + Annotations** and use **Open annotation
in Zotero** below the highlight in the generated Markdown. See the
[annotation-link guide](../LINKS.md#copy-a-pdf-page-or-annotation) for file locations.

## Verification

Regression tests cover directly reachable annotation commands, all three link
formats, unsupported selections, command-time validation, and the exported
Markdown link workaround. Export tests distinguish success, missing files, and
failures, and check that result text is displayed without interpreting markup.
All 59 JavaScript, 98 Python, and 18 Emacs tests pass
locally; the Emacs picker check disables native trampolines to avoid a local
compiler configuration error. The XPI build, checksum/feed validation, and archive
integrity checks pass. The renderer behavior was checked against Zotero
10.0.4's installed reader source. CI passes on macOS, Windows, and Linux.
Live checks of the updated result dialog and annotation menu remain unverified;
Zotero 9 has not been tested live for this patch.

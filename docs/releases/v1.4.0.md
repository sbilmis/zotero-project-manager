# Zotero Project Manager (ZPM) 1.4.0

**Draft — not yet released.** The current public release is
[1.3.2](https://github.com/sbilmis/zotero-project-manager/releases/tag/v1.3.2).

Export several Zotero collections in one operation. ZPM 1.4.0 adds support for
Zotero 10's multiple collection selection, with a shared destination and a clear
result for each exported workspace. New quick-start guides cover the plugin,
Markdown and Org links, and optional Emacs integration.

## What's new

- **Export multiple collections.** Command-click on macOS or Ctrl-click on
  Windows/Linux to select collections, then right-click a selected row and choose
  **ZPM → Export → Collection** or **Collection + Annotations**. Each selected
  root gets its own workspace under the same destination.
- **Handle overlapping selections.** Selecting both a parent and its child
  exports the child once, inside the parent's workspace. You can also export a
  subcollection on its own; its parent and siblings are excluded, as in previous
  versions.
- **See the whole result.** One dialog reports exported workspaces, file counts,
  and failures. If one collection fails, the others continue. Failed exports
  may have written some files; resolve the reported error and export again.
- **Get started faster.** Short guides explain installation, first and repeat
  exports, Markdown/Org links, and Emacs setup. A tutorial recording script is
  included; a video is not yet available.

## Compatibility and upgrade

| Component | Supported version / change |
| --- | --- |
| Zotero plugin | ZPM 1.4.0; Zotero 9 and 10.0.x |
| Multiple collection selection | Requires Zotero 10 |
| Python CLI | Remains at 1.3.2; no CLI upgrade is needed for this feature |
| Exported workspaces | No new workspace migration; existing filename and layout settings are retained |
| Markdown/Org links and Emacs | Existing links and all five picker commands remain available; no new Emacs setup is required for this update |

**After 1.4.0 is published**, existing users can run **Tools → Plugins → gear →
Check for Updates**. For manual installation, download `zpm-zotero-1.4.0.xpi`
from the 1.4.0 GitHub release and choose **Install Plugin From File…** in the same
gear menu. Install over the existing plugin and restart Zotero if prompted.
Confirm **Zotero Project Manager (ZPM) 1.4.0** is enabled. The Add-on Market may
show the new version later, after its catalog refreshes.

## Export behavior and limitations

- Repeat exports remain incremental: matching files are skipped; new or changed
  files are copied in full. This is file-level synchronization, not rsync's
  block-level transfer.
- Exports are **one-way: Zotero → folder**. Changes made in an external PDF
  reader are not imported into Zotero and can be overwritten on re-export.
  Zotero annotations are exported separately as Markdown.
- Select collections from one library at a time. Library roots and saved
  searches cannot be included in an export selection.
- Collection **Copy Link** and the Emacs picker when following Zotero's selection
  still require one selected collection. A collection remembered in an Org note
  continues to work independently of the sidebar selection.

## Verification

All 55 JavaScript tests, 90 Python tests, and 18 Emacs tests pass, including CI.
Export tests cover overlapping roots, name collisions, repeat exports,
cancellation, and partial failures using temporary files. The XPI builds
reproducibly and matches the update feed's SHA-256 checksum.

The preview is installed and enabled in Zotero 10.0.4. **Before publication:**
complete the live multi-selection menu and export checks described in the

# Zotero Project Manager 1.1.0

A maintenance release for Zotero 9 with the same standard export feature set as
public 1.0.0. The simplified preview was manually confirmed by the project owner.

## Fixes

- Settings now initializes correctly: saved values load and controls respond.
- **Choose…** opens a folder-selection dialog attached to Settings. Cancel keeps
  the saved folder; stale starting paths and picker failures can be recovered from.
- Concurrent plugin exports are blocked to prevent overlapping workspace writes.
- Expanded regression coverage and installation/testing documentation.

## Unchanged workflow

The collection menu contains **Export Collection**, **Export Collection +
Annotations**, and **Settings…**. Standard exports, annotations/child notes,
filename/layout settings, incremental updates, and read-only safeguards remain.
The core export engines are unchanged from public 1.0.0.

The experimental Gemini Notebook/DEVONthink integrations are **not included**.
Users of the previews keep all existing exported folders, notebooks, and DT4
records; nothing is deleted or automatically migrated. Standard public 1.0.0 users
do not lose any app-integration feature, since those features were never released.

## Install or update

In Zotero, use **Tools → Plugins → gear → Check for Updates**. Automatic updates
are available when enabled. Both 1.0.0 and 1.1.0 preview installations can upgrade.

Alternatively, download the attached **zpm-zotero-1.1.0.xpi**, then choose
**Install Plugin From File…** in the same menu. Install over the existing plugin;
no uninstall is needed. Restart Zotero if requested.

Add-on Market may take time to refresh its catalog/mirrors. If it still lists
1.0.0, use Zotero's updater or the direct XPI instead of Reinstall.

The Python CLI is optional and independent of the plugin. For users who configured
an experimental CLI Notebook project, the removed profile now produces an explicit
migration message. Review the output folder/layout before removing that setting to
switch deliberately to standard export. Ordinary standard projects remain compatible.

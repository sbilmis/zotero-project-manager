# Zotero Project Manager (ZPM) 1.3.2

ZPM now supports **Zotero 10.0.x** while retaining Zotero 9 compatibility. The
plugin's full display name is **Zotero Project Manager (ZPM)**; menus and settings
keep the short **ZPM** label.

## Install or update

Download `zpm-zotero-1.3.2.xpi` from this release and install it over the existing
plugin using **Tools → Plugins → gear → Install Plugin From File…**. Existing
installations can also use **Check for Updates**. The previous 1.3.1 package is
limited to Zotero 9.

Add-on Market will offer the Zotero 10 release after its external catalog and
mirrors refresh. The plugin is already registered; no new listing is needed.

## Fixes

- Update exports, collection links, and the Emacs picker for Zotero 10's plural
  selection APIs. Select exactly one collection for these actions; multiple or
  mixed collection/search selections receive a clear error.
- Preserve ordinary item/PDF links and remembered Emacs collections. All five
  picker commands and the Org collection/item/PDF link handlers remain available.
- Add Zotero's allowed-request header and current setup instructions to the
  Emacs picker module. The existing Emacs client also remains compatible.
- Verify that update-feed compatibility matches the installer's manifest and
  run Emacs link/picker tests in CI.

## Export behavior

Exports remain **one-way and incremental**: matching PDFs are skipped and new or
differing PDFs are copied in full. Edits made to exported PDFs are not sent back
to Zotero and can be overwritten on re-export. Zotero annotations and notes are
exported separately as Markdown. Bidirectional sync is not implemented.

## Validation

90 Python tests, 50 JavaScript tests, and 18 Emacs tests passed locally. The
compatibility fix was installed and verified active in Zotero 10.0.4, and the
running Emacs picker successfully retrieved papers from the selected collection.
Export tests used isolated fixtures. The XPI is reproducible and checked against
the update feed's SHA-256 digest.

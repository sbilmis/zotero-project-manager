# ZPM — Zotero Project Manager 1.3.1

This update shortens Zotero context menus and settings to **ZPM**. The installed
plugin is named **ZPM — Zotero Project Manager** so it remains easy to recognize.
The README and current menu guides use the same naming.

Existing links, exports, Emacs commands, preferences, package names, plugin ID,
and update URLs are unchanged. No Emacs configuration changes are required.

## Update

In Zotero, choose **Tools → Plugins**, open the gear menu, and choose
**Check for Updates**. Alternatively, download `zpm-zotero-1.3.1.xpi` from this
release and use **Install Plugin From File…**. Restart Zotero if requested.

Verify that the context menu and settings entry show **ZPM**, and that the plugin
list shows **ZPM — Zotero Project Manager** version **1.3.1**.

## Validation

Python and plugin tests pass. The versioned XPI was built and checked against the
update-feed SHA-256. Installing and visually checking the new names in Zotero
remain manual checks; the release process does not install the plugin.
